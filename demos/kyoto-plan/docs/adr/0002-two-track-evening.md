# ADR 0002 — 夜間改為雙軌，當日 18:15 決策

- 狀態：已採納（修訂 [ADR 0001](0001-anchor-the-day-on-the-1930-show.md)）
- 日期：2026-09-05

## 背景

ADR 0001 無條件把 19:30 うずまさ百鬼夜行 當成全日錨點，並據此把晚餐降級為園內小食。
但真正的約束後來釐清為**「不想讓 ともちゃん 太晚回去」的社交約束**（非末班車）。

推算後發現一個反直覺的結果：提早離園去河原町吃飯，
不但能吃到正餐，回家時間還**比留下看秀早 30 分鐘**。

## 決策

夜間不預先定案，**攻略頁並列兩案，當日 18:15 由 ともちゃん 的狀態決定**。

### プランA — 提早切上，河原町吃飯

| 時間 | 內容 |
|---|---|
| 17:00–18:30 | 映画村（17:30 遊行順路看・江戶街夜景・グリーティング）。YOKAI フード 只淺嚐 |
| 18:30 | 離園（**散場人潮之前**，嵐電不必等） |
| 19:05 | 抵京都河原町 |
| 19:10–20:25 | 晚餐 —— **第一希望：京家 きよみず**（京都風おばんざい・地酒）。此時段菜單完整、無 L.O. 壓力 |
| 20:45 | 鴨川四条大橋 散步 |
| 21:00 | 阪急発 → **21:45 大阪梅田** |

### プランB — 看完主秀直接解散

| 時間 | 內容 |
|---|---|
| 18:00–19:20 | 烏通り YOKAI フード 邊走邊吃 ＝ 晚餐 |
| 19:30–20:00 | うずまさ百鬼夜行（主秀） |
| 21:00 | 抵京都河原町 → 鴨川散步 |
| 21:30 | 阪急発 → **22:15 大阪梅田** |

### 決策點

- **18:15 前** 決定。留過 18:30 即等於選定 B（18:30–19:30 只剩等待）
- 想吃飯就**從園內先打電話**問位子（京家 きよみず 075-201-1127）。A 是 18:00 前，B 是 19:00 前
- B 之後（21:15 抵達）京家 仍有 45 分鐘（L.O. 22:00），趕不上或満席才改 TATSUNOSUKE（L.O. 深夜 2:00）

## 理由

兩案差距只有 30 分鐘，但內容天差地別。與其替對方預判體力，
不如把「代價」算清楚攤在頁面上，當天看她的狀態決定。

A 的附帶好處是避開 20:00 全園散場 —— 嵐電是 1〜2 節路面電車，
散場時可能擠不上第一班。18:30 離園完全不碰這個瓶頸。

## 代價

- 選 A 會錯過**當晚唯一的主秀**，而那是這張夜間票的核心內容
- 選 B 則整天沒有一頓坐下來的正餐（除非接受滑進 京家 的 45 分鐘，回家時間變 23:15）
- 攻略頁複雜度上升：夜間需呈現分歧與各自代價，不能只畫一條線
