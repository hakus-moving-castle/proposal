# ADR 0001 — 以 19:30「うずまさ百鬼夜行」為全日錨點，晚餐降級

- 狀態：已採納
- 日期：2026-09-05
- 行程日：2026-09-20（日）

## 背景

原始規劃（Gemini 稿）把太秦映画村的遊行當成一場活動，時間抄了 17:30、
體驗描述抄了「卡位、站前排、拍無遮擋正面」。查證後發現是兩場不同活動：

- **TWILIGHT パレード（17:30）** — 參加型，需事前申込、穿妖怪服裝、服裝事前審查
- **うずまさ百鬼夜行（19:30）** — 觀賞型，音樂＋舞蹈＋殺陣，終場與妖怪共舞

原案因此推導出「18:50 離園 → 19:40 河原町居酒屋晚餐 → 21:00 送車」，
建立在一個不存在的結束時間上。

同時確認：9/19〜9/22 映画村全域營業至 21:00（涵蓋行程日），
已購入 17:00 ナイトタイム入村券。

## 決策

**以 19:30 うずまさ百鬼夜行 為全日唯一錨點**，其餘時段全部往它對齊。

連帶決定：

1. **不申請 17:30 參加型遊行** —— 無裝扮意願，看點有限；遇到就順路看
2. **晚餐降級為 18:00–19:20 烏通り YOKAI フード 邊走邊吃**，不吃園內 喜らく 正餐
3. **河原町不排任何餐飲**，只保留鴨川四条大橋散步與送車
4. **甜點升格為下午主場**（15:20–16:30 Sweets Cafe KYOTO KEIZO）

## 理由

同行者 ともちゃん **胃口不大、偏好咖啡廳甜點**。在此前提下，
原案的「午餐 → 甜點 → 園內正餐 → 園內小食」等於六小時內四餐，
且甜點前僅隔 45 分鐘 —— 對方最想要的一段反而吃不下。

錨定 19:30 後，正餐只剩午餐一頓（蕎麥麵，輕且快），
甜點與園內小食各隔 90 分鐘以上，且兩個「輕」都符合偏好。

「20:50 才抵達河原町再吃正餐」對累了一天的來客本就不現實，
放棄居酒屋不是損失，而是承認它從一開始就排不進去。

## 代價

- 放棄「京都風居酒屋・おばんざい・地酒」這個體驗。園內餐飲是主題樂園型（拉麵・定食・攤位），拿不到這個氛圍
- 若 YOKAI フード 份量不足或想坐下來，需臨場改走 喜らく（18:00 前後，可能需等位）
- 全日結束時間往後推至 21:00 後才送車

## 替代方案

- **只看 17:30 場**：可保住河原町 19:40 正餐，但那是參加型遊行，無裝扮者只能旁觀，且錯過主秀
- **兩場都看＋園內 喜らく 正餐**：撞上 18:00–19:20 人潮高峰，且與甜點間隔僅 90 分鐘、對小胃口過量
