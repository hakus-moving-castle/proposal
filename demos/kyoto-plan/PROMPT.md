# 京都一日プラン — 2026.9.20（日）

## 由來

原始素材是使用者與 Gemini 討論出的一日行程草稿（京都水族館 → 三条会商店街 → 太秦映画村 → 河原町）。
本專案透過 `/grill-with-docs`（`/grilling` + `/domain-modeling`）逐項拷問並查證，
再產出交付物：**給同行者 ともちゃん 看的日文單頁攻略（PWA）**。

## 交付物需求

- **日文單一語言**（不做 zh-tw / en，不放語系切換器）
- **淡雅舒服**的視覺（生成り紙色 + 明朝體標題，非 Premium Dark）
- **Google Maps 連結**：每段移動一顆 transit 導航連結（即時班次）、每個店家一顆地點連結
- **information icon 理由注記**：每個選擇旁附 ⓘ，點開說明「為什麼這樣選」
- **京都水族館 QR × 2**（ともちゃん／ハク），可點擊全螢幕放大供工作人員掃描
- **夜間兩案並列**（A／B），標示各自回家時間，並寫明「看當天精神狀況決定」
- **PWA**：可加入主畫面、離線可開（QR 內嵌，圈外也能在改札前顯示）
- 無 build step，單檔可直接開啟

## 查證中推翻的原始內容

Gemini 草稿的下半天建立在錯誤事實上，主要修正：

1. **日期是 9/20（日）不是週六** — 由水族館 QR 票面確認
2. **遊行有兩場，草稿混成一場**
   - TWILIGHT パレード 17:30 ＝ 參加型（需事前申込、服裝審查）
   - うずまさ百鬼夜行 19:30 ＝ 觀賞型（草稿描述的體驗其實是這場）
   - 草稿因此推導出不存在的「18:30 結束 → 19:40 河原町晚餐」
3. **推薦餐廳半數查無此店** — 「生そば 鶴㐂」「手打ち蕎麦 柏」「そば処 やまもと」「百練」皆查無；
   「珈琲工房 寺町」正確名稱為「珈琲工房 てらまち」
4. **KEIZO 有兩間店** — 10分モンブラン 只能在有座位的 Sweets Cafe 吃，
   商店街內的 KEIZO OKASHI 是外帶專門店
5. **市バス 207 是循環系統**，兩個方向的終點都標「東福寺」，須認「東寺」二字
6. **真正的約束不是末班車**，而是「不想讓對方太晚回去」的社交約束

## QR 處理與驗證

攻略頁的放大用 QR 經過處理（從票券圖中精確裁出 QR 本體 87×87px，
補 5 模組純白靜空區，再以最近鄰整數倍放大至 702px），並以 CoreImage `CIDetector`
解碼比對：**處理後的 payload 與原圖完全一致**，且已從 `index.html` 反向抽出再驗一次。

原始票券圖 `qr-1-tomochan.png` / `qr-2-haku.png` **僅保留在本機**，
已列入 `.gitignore` 且從部署排除 —— repo 為 PUBLIC，明文 QR 一旦上線
就能被直接下載，密碼閘會完全失效。

`CONTEXT.md` / `PROMPT.md` / `docs/` 同樣不部署（內部規劃文件）。

## 偏離 create-demo 慣例之處

| 慣例 | 本案 | 原因 |
|---|---|---|
| 三語 i18n + `i18n/` 目錄 | 只做日文，無 i18n | 讀者只有 ともちゃん 一人 |
| Tailwind CDN | 手寫 CSS | 手機現場使用，避免 CDN 阻塞渲染；且需自訂明朝體排版 |
| — | 新增 PWA（manifest / sw.js / icons） | 使用者要求可放主畫面、隨時點開 |
