## 交付物形態

**PWA**
攻略頁為 PWA（`manifest.webmanifest` + `sw.js` + icons），可加入手機主畫面、離線開啟。
圖示為 Gemini 產生的狐狸圓形 logo（`logo-source.jpeg`，僅存本機、不進版控）。
裁切方式：以**圓環十字掃描**求出真正圓心 (1166, 853) 與直徑 976，
再裁成 1162px 方形（logo 佔畫面 84%，確保 Android maskable 圓形遮罩不切到圓環）。
→ 若要重裁，**不要用整體 dark-pixel bbox** —— 右下的雲會把 bbox 撐大，圓心會偏。
**Service Worker 只在 HTTPS 下生效** —— 雙擊本機檔案（`file://`）不會註冊，
需透過 GitHub Pages 網址才能安裝與離線使用。

**QR 內嵌（Inlined QR）**
兩張 QR 以 data URI 內嵌於 `index.html`，不走外部檔案。
理由：改札前若圖檔載不出來，整張票就失效 —— 內嵌讓 SW 快取 index.html 即等於快取票券。

**放大用 QR 的處理與驗證**
從票券圖精確裁出 QR 本體（x107–193, y40–126，87×87px，不含任何文字），
補 5 模組（15px）純白靜空區，最近鄰整數倍放大 6× 至 702px。
以 CoreImage `CIDetector` 解碼驗證，處理前後 payload 一致，並自 `index.html` 反向抽出再驗一次。
→ **任何再次改動 QR 圖像，都必須重新解碼驗證。**

**為何指定京都河原町上車**
1. **阪急京都線的起站** —— 排隊就一定有座位。走了一整天，座位優先於少走幾步

## 存取控制

**密碼閘（Password Gate）**
密碼 `0920`。輸入後寫入 `localStorage['kyoto-plan-pw']`，同一裝置不再詢問（不設失效）。

**實作方式不是「遮住畫面」，而是真的加密**：
兩張 QR 的 PNG 以密碼導出的 keystream（FNV-1a 種子 + xorshift32）XOR 加密後 base64 內嵌，
另存明文的 FNV-32 校驗值。密碼正確才解得出、校驗才通過。
→ **看原始碼也拿不到 QR。** 不用 WebCrypto，故 `file://`、離線、舊瀏覽器皆可用。

**這道鎖擋得住什麼、擋不住什麼**
- ✅ 擋得住：只知道網址的人、搜尋引擎（另加 `robots: noindex,nofollow`）
- ❌ 擋不住：**4 位數密碼可被暴力破解（僅一萬種）**。真要提高強度就換長一點的密碼
- ❌ 擋不住：頁面的**行程文字仍在原始碼中**（只有 QR 被加密）
- ⚠️ repo 為 **PUBLIC** —— 這是這道鎖存在的原因

## 登入畫面的背景演出

密碼畫面的背景把「水族館 → 百鬼夜行」整天的跨度畫出來，
**刻意做少數幾個大尺度元素**（初版做了 11 個小元素，太瑣碎）：

| 元素 | 尺寸 | 週期 | 來自 |
|---|---|---|---|
| 巨大なクラゲ | 280px，緩慢上昇＋左右搖擺 | 46s / 12s | 京都水族館（クラゲワンダー） |
| 水の波紋 ×2 | 擴散至 820px | 16s（錯開 8s） | 水族館 |
| 百鬼夜行の行列 | 高約 114px，一團橫越 | 46s | 太秦映画村 |
| 青海波 | 高 180px，緩慢平移 | 38s | logo 的波紋呼應 |

行列的三個妖怪：**唐傘小僧**（一目一足の傘）、**ろくろ首**、
**提灯を持つ狐**（走在最前頭）。
→ 狐は站上 logo 的呼應，且「狐火・狐の嫁入り」本就屬日本妖怪譜系。
→ **不要用西洋萬聖節式的圓身波浪底幽靈** —— 初版用過，調性不對。

**狐の作図で踏んだ罠（再修正時の注意）**
1. 鼻先を細長い針にすると鳥のくちばしに見える → **短く厚い楔形**にする
2. 尾の内縁を体の輪郭より外側で止めると、間に**背景色の隙間**が出る
   → 内縁は体（背側 x≈32–38）に**重ねる**
3. 尾を横に膨らませると丸い球になる → **縦に伸ばして先を細く**、尻から上へ跳ね上げる
4. 提灯は竿の横に置くと浮く → **横木を付けて吊り下げる**
5. 腕は竿まで**届かせる**（途中で止めると宙に浮いた棒に見える）
6. 尾先の白い斑点は小さすぎて光の汚れに見えた → 入れない

> 小さい表示・低不透明度のままでは形の崩れが判定できない。
> 検証時は `.gate-box` / 他レイヤーを `display:none` にし、
> `.parade` を `width:230%; opacity:1; animation:none` にして拡大して見る。

**狐の作図で効いた手法**
- **頭と両耳を一本のパスで描く** → 耳と頭の隙間・耳間の谷間が構造的に発生しない
- 尾は体に**重ねたまま**、境目に紙色の細い線（幅1.5・不透明度.38）を**継ぎ目として引く**
  → 隙間を作らずに「体と尾を分ける」。パスを離すと必ず背景色が漏れる
- 口は鼻先まで届かせない（先端まで引くと嘴が割れて見える）


全部 `aria-hidden` + `pointer-events:none`，`prefers-reduced-motion` 下整層 `display:none`。

## 時間軸の点 — 位置合わせで踏んだ罠

**症状**：空心の丸が進行線から右に約 1px ずれ、中に入れた実心の点も
さらに 0.5px ずれる。3回直しても直らなかった。

**原因は2つ重なっていた**

1. **擬似要素に `box-sizing:border-box` は効かない**
   `*{box-sizing:border-box}` の `*` は `::before` / `::after` に一致しないため、
   これらは `content-box`。border は width の外側に付く。
2. **`border:1.5px` はデバイスピクセルに吸着して 1px になる**
   結果 painted 幅が 9+1+1 = **11px（奇数）** になり中心が半端な位置に来る。
   4px（偶数）の内側の点はそこに中心を合わせられない。

**解**：`border:1px` / `width:10px` にして painted 12px（偶数）にする。
中心が整数に乗り、内側の点と揃う。

**検証方法の教訓**
`getComputedStyle` の `borderWidth` は **1.5px を 1px と報告する**ため、
それを使った計算は必ず 0.5px 狂う。
→ **同じ値で実 div を作り `getBoundingClientRect()` で painted box を測る。**
擬似要素には rect が無いので、この代理測定が唯一信頼できる。

## 夜のいろ（ダークモード）

**切り替えの規則**：`17:00〜06:00` なら夜。**時刻だけで決める。**

> 当初 `OS が dark || 時刻` にしていたが、端末を常時ダークにしていると
> OS 条件が常に真になり、朝でも夜モードになってしまった（実機で発生）。
> 「時刻で切り替える」という要件に対して OS 設定に拒否権を持たせてはいけない。
> `prefers-color-scheme` はもう見ていない（診断パネルに表示はするが未使用）。

17:00 は映画村の入村時刻。行程が夜に入る瞬間に、攻略ページ自身も夜になる。
`?theme=night` / `?theme=day` で上書きできる（確認用）。
FOUC を避けるため `<head>` の早い段階で判定し、以後は 1 分ごと・
復帰時・OS 設定変更時に追従する。

**QR の全画面だけは、どちらのテーマでも白のまま。**
読み取り機は高コントラストの白地を要る。`#qr-ov` 配下は変数を一切使わず
色を直書きしてあるので、構造的にテーマの影響を受けない。**ここは凝らない。**

**擬似要素・SVG の「抜き」は必ず `var(--paper)` を使う**
妖怪や狐の目は暗い剪影に開けた穴。夜は剪影が明るくなるので、
目の色も背景に追随しないと消える。`fill="#FAF8F3"` のような直書きは不可。
→ `style="fill:var(--paper)"` で指定する（SVG の presentation attribute は
`var()` を解釈しないため、attribute ではなく style で書く）。

**光りものは夜に強める**：提灯の box-shadow、円相の stroke。
明るい地では光暈はほとんど読めないので、淡色時の値のままだと夜に物足りない。

## app icon は時刻で変えられない

iOS の PWA はホーム画面に追加した時点でアイコンが固定され、
`apple-touch-icon` を再取得しない。動的に差し替える Web API も無い
（`setAlternateIconName` はネイティブ専用）。Android も同様。
変えられるのはブラウザのタブの favicon だけ。
→ **できない前提で設計する。** 代わりに `theme-color` を切り替えて
アプリの上下の余白の色をテーマに合わせている。
