# 0001 — 清水寺排傍晚，不做「07:30 早攻」

- 狀態：**採用**
- 日期：2026-09-12

## 脈絡

原始草稿把清水寺排在 9/18 早上 07:30，理由是「趕在觀光團之前到」。這是京都行程的標準做法，網路上幾乎所有攻略都這樣寫，而且它在單日行程裡確實有效。

但這趟不是單日行程，是七天，而且同行的是媽媽和姊姊。把 9/19 的 07:30 到達往回推，起床時間是 **05:40**，而它前面還接著 9/18 的 06:50（鞍馬）、後面接著 9/20 的 06:50（KKday）、9/22 的 07:00（金閣寺）—— **連續四個早起日，其中一個要求 05:40**。

使用者對這趟旅行的原話是「不排斥早起但不想要那麼趕，想要輕鬆一點的旅行」。

## 決策

**清水寺改排 16:00 進場**，動線一律由上往下：清水道下車 → 清水寺 → 三年坂 → 二年坂 → 八坂の塔 → 八坂神社 → 祇園四条，終點就是車站。

9/19 的上午改給下鴨神社糺の森與鴨川跳石，09:30 出門即可。

## 理由

早攻戰術的前提不是「早起有效」，而是「**每天都爬得起來**」。第一個前提是真的，第二個在第三天就會破。一旦某天崩掉，那天的清水寺會落在 09:00 之後 —— 也就是連假期間最糟的時段，比原本傍晚去還差。

相對地，**傍晚退潮是不需要任何人努力就會發生的事**：觀光巴士有回程時間，下午四點以後幾乎都走了。它的效果不依賴任何人的意志力，因此在七天的尺度上比早攻更可靠。

附帶的好處是動線變成全程下坡，對膝蓋友善；以及夕照斜打在清水舞台上，比早晨的平光好看。

## 取捨

- **放棄**：清晨無人的清水寺。那確實是更極端的無人體驗，早攻成功時的上限比傍晚高。
- **換得**：一個不會崩的行程、一天下午的空白休息時間、以及一條不需要爬坡的收尾路線。

這是拿「最好情況的上限」換「最壞情況的下限」。在同行者體力不明、而且連續六天走路的前提下，守下限比拚上限重要。

## 後果

- 9/19 上午空出來 → 給糺の森（媽媽要的「大自然、人少」），而且**鴨川跳石需要不增水，剛好押在全程降雨機率最低的一天（30%）**。
- 9/19 下午刻意留白回民宿休息，這段空白不得再塞行程。
- 二三年坂的店家多半 17:00–18:00 打烊，傍晚走過去時店還開著，但要在 18:00 前逛完。
